\# TouchPoint Platform



TouchPoint is a task-based NFC interaction platform designed to turn intentional physical taps into meaningful digital actions.



\## Initial Use Case

\- Classroom attendance using NFC cards or phones

\- ESP32 + PN532 as the tap device

\- Web and mobile-friendly UI

\- Backend API and database for logging actions



\## Repository Structure

\- docs/ – assignment PDFs, architecture notes

\- firmware/ – ESP32 and NFC reader code

\- backend/ – API and server logic

\- app/ – React Native (web/mobile) application

\- figma/ – prototype references



\## Status

Early prototype and research phase (PPIV coursework).
